# hingeport

Hinge CSV/TSV port tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/hingeport/

## Install / run

```bash
git clone https://github.com/theworker02/hingeport.git
cd hingeport
node src/cli.js
node --test
```
